## 8. Campus Drive Suggestions & Concept Weakness Diagnosis Demo Guide

This feature demonstrates end-to-end AI-driven skill matching, drive suggestions, and remediation when technical or soft skill gaps exist.

### Scenario A: Primary Account (`gowthamcd.23cse@kongu.edu` / `Password@123`)
* **Opportunities URL**: [`https://localhost:5173/opportunities`](https://localhost:5173/opportunities)
* **Student Dashboard**: [`https://localhost:5173/student/dashboard`](https://localhost:5173/student/dashboard)
* **Concept Weakness & Skill Explorer**: [`https://localhost:5173/student/skills`](https://localhost:5173/student/skills)

#### What to Verify:
1. **High / Moderate Match Drives**:
   - **Grito Technologies** (Full Stack Web Engineering, ₹14.50 LPA): **71% Match** (`MODERATE_MATCH`) — Frontend & Backend skills (HTML, JS, React, Java, PostgreSQL) matched. Eligible to apply directly.
   - **Infosys** (Specialist Programmer, ₹12.00 LPA): **67% Match** (`MODERATE_MATCH`) — Java, Python, SQL, JavaScript matched.
   - **Mr. Cooper** (FinTech Java Microservices, ₹13.50 LPA): **67% Match** (`MODERATE_MATCH`) — Java, Spring Boot, React, SQL matched.
2. **Skill Gap & Critical Attention Drives**:
   - **Zoho Corporation** (Core Systems, ₹16.00 LPA): **0% Match** (`SKILL_GAP_CRITICAL`) — Missing *C++, Rust, DSA, Distributed Systems, Operating Systems, Systems Thinking*.
   - **Presidio** (Cloud Solutions, ₹15.00 LPA): **17% Match** (`SKILL_GAP_CRITICAL`) — Missing *AWS, Terraform, Kubernetes, Verbal Communication, Client Articulation*.
   - **Soliton Technologies** (Embedded Systems, ₹11.00 LPA): **33% Match** (`SKILL_GAP_CRITICAL`) — Missing *C++, Embedded Systems, Signal Processing, Analytical Reasoning*.
3. **Automated Diagnostic & Remediation Flow**:
   - For any drive with a skill gap, the UI displays: **"🚨 Skill Gap Detected · Critical Attention Required"** with a detailed 2-column breakdown of Matched vs Missing technical & soft skills.
   - Click **"Train in Concept Weakness Diagnosis"**: Directly routes to `/student/skills` where the **Critical Attention Required · Campus Drive Eligibility Impacted** banner lists exact diagnosed weakness patterns (e.g. Python primitive types, CSS layout semantics) and actionable remediation steps.
   - Click **"Launch 50/50 Adaptive Retest"**: Generates a customized adaptive practice test enforcing **50% questions on weak concepts + 50% broader concepts** to accelerate eligibility.
