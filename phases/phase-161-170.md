Beyon's key distinction

The recruitment system now combines three independent mechanisms:

Institution channel

Company → Institution → Eligible placement-willing students

Independent channel

Student → Search → Eligibility → Beyon Coins → Apply

Intelligence channel

Skill Graph → Match → Assessment → Shortlisting → Hiring

This keeps the original Beyon concept intact while making the recruitment lifecycle complete.
