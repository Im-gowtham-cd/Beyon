Critical architecture decision

For Beyon, keep the responsibilities separated:

Beyon Web
→ Account / Company / Institution / Opportunity / Application

Beyon Backend
→ Authentication / Eligibility / Coins / Assessment Session / Results

Beyon Desktop
→ Exam UI / Camera / Microphone / Screen Monitoring / Secure Exam Environment

Assessment Engine
→ Answer Evaluation / Coding Execution / Scoring

Proctoring Engine
→ Events / Evidence / Risk Score / Review

This separation will make the system much easier to scale and secure later
